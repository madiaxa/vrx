# VRX artwork and numeric font

The logo (and all variants thereof) depicts the Greek letter phi with a line to make it look like a bit more like an 'R'. macOS bundles use VRX.icns; native Windows MSVC builds embed VRX.ico; native window-manager icons use the same logo.

Axa Mono is the bundled OFL numeric font. The copyright and SIL Open Font License are in OFL.txt. The font is embedded for numeric controls, including Pitman dozenal digits. RSVP words use the independently selected reading font. Custom digit alphabets and balanced-ternary symbols can be edited in the app.
