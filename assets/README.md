# VRX artwork and numeric font

`logo.png` is the original logo supplied by the user, preserved unchanged with its white background. Generated ICNS, ICO and raw window-icon pixels are size variants of that artwork. macOS bundles use VRX.icns; native Windows MSVC builds embed VRX.ico; native window-manager icons use the same logo. The artwork is not part of the reading interface.

Axa Mono is the bundled OFL numeric font. Its family, full, unique and PostScript names were changed to Axa Mono; glyphs and metrics are retained. The original copyright and SIL Open Font License remain in OFL.txt. The font is embedded for numeric controls, including Pitman dozenal digits. RSVP words use the independently selected reading font. Custom digit alphabets and balanced-ternary symbols can be edited in Personalize.
